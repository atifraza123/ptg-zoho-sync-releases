## What is new in 1.6.0 (13 Nov 2026)
- New look: sidebar navigation, Overview page with live counts and quick actions, cleaner cards.
- Windows installer (Setup.exe): installs per user, Start menu and desktop shortcuts, no Python needed.
- Your settings, keys and sync history stay in %APPDATA%\OdooZohoSync - updates never touch them.
- Help > What's new and About show the version; new versions are published on GitHub.


Install: download PTG-Zoho-Sync-Setup-1.6.0.exe and run it (no administrator rights needed).

Windows SmartScreen may say *"Windows protected your PC"* because the installer isn't code-signed yet: click **More info → Run anyway**.

To check the download (optional), compare its SHA-256 with the .sha256 file.
